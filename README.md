# Mesa de Bar Game

Protótipo de jogo feito com [Phaser 3](https://phaser.io/) e Vite.

## Como executar

1. Instale as dependências:

   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

3. Abra no navegador o endereço exibido no terminal (geralmente `http://localhost:5173`).

## Controles

- Setas do teclado ou `WASD`: movimentar o personagem.
- Colete as moedas da mesa para marcar pontos.
